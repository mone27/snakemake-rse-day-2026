# Snakemake for flexible and scalable data pipelines - Belgium RSE Day 2026

## Abstract

Is your data processing a collection of bash scripts? The answer is probably yes, as it is the starting point of all projects. However, high-quality research requires a better approach; Research software  needs to be be reproducible,  transparent, scalable and be adaptable to the evolving research methods and questions.  
There is an entire field, data engineering, that develops  scalable and robust data pipelines. Those approaches are, however, designed for industry production environments, thus lack the flexibility needed in a research setting. 
Snakemake provides a solution with easy-to-use and flexible data pipelines. The pipelines are defined as a graph of rules, that declare the commands to generate an output file from the input. From this, snakemake determines what needs to be executed, scaling seamlessly from a laptop to a HPC cluster. The use of a pipeline definition ensures that the processing steps are reproducible and understandable. Moreover, snakemake provides nice-to-have features like provenance information and all additional functionality like logging, benchmarking and managing software dependencies. The flexibility comes from the use of python in the rules definitions and that files can modified outside of a pipeline.  
In the talk I will introduce snakemake and how I use it to accelerate my research, with a particular focus on how it enabled me to use HPC clusters. The aim is to add snakemake to the researcher’s toolbox supporting the development of high-quality data processing pipelines.
